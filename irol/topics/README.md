# topics — 연구주제 문서

연구원 배정용 주제 제안·실행 계획을 모은다. 계속 리비전하는 문서이므로 아래 규칙을 따른다.

## 파일명 규칙

- `<대상>-<범위>-<종류>.md` 형식의 **고정 슬러그**. 날짜·버전은 파일명에 넣지 않는다 (링크가 깨지지 않게).
  - 대상: `msc`(석사) · `phd` · `postdoc` · `ug`(학부)
  - 범위: `lowlevel-rl` · `perception` · `integration` 등 로드맵 갈래
  - 종류: `topics`(주제 제안) · `plan-<학생>`(개인 실행 계획) · `review`(중간 검토)
- 리비전은 문서 상단 표(현재 리비전 + 리비전 이력)와 git 히스토리로 관리한다. 큰 방향 전환만 r_N을 올리고, 표현 수정은 커밋만 한다.
- 문서를 폐기할 때는 삭제하지 않고 상단 상태를 "폐기 — 대체: <파일>"로 바꾼다.
